0시작하기

상단에 탭 5개와 버튼 2개가 전부입니다.

  • 보드 · 훈련 디자인 · 일정 · 게임모델 · 스카우트 — 도구 전환 탭
  • 공유 — 지금 보고 있는 작전판·세션·주간 일정을 링크로 복사
  • ⚙ 설정 — 언어(한·日·EN), 백업 내려받기/복원, 화면 미리보기
📱 폰에서 자주 쓴다면 브라우저 메뉴의 "홈 화면에 추가"를 해두세요. 앱처럼 열립니다.
데이터는 이 기기 브라우저에 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우면 사라지니, ⚙ → 백업 내려받기를 습관으로 해주세요.

1보드 — 작전판

전술을 그리고, 애니메이션으로 만들고, 이미지·영상으로 내보냅니다.

선수 배치

  • 상단 벤치의 번호 알을 끌어다 놓거나, 필드를 비운 상태에서 포메이션(4-4-2 등)으로 11명 자동 배치
  • 알 더블클릭(더블탭) → 선택: 크기 −/＋, 복제, 좌우/상하 대칭, 삭제
  • 공도 더블탭하면 크기 조절이 됩니다

그리기

  • 툴바: 이동 / 런(점선) / 패스(직선) / 드리블(물결) / 직선 / 점선 / 펜 / 구역 / 사각형 / 텍스트 / 지우개
  • 보기 ▾에 그리드(5레인·20존·삼등분)·명단, 더보기 ▾에 저장·내보내기

애니메이션

  • ▶ 애니메이션 → ＋ 장면으로 장면을 추가하며 알을 옮기면 자동 보간
  • 👻 어니언스킨: 이전 장면 위치가 반투명으로 겹쳐 보여 다음 장면을 만들기 쉬워요
  • 완성되면 재생·반복·속도 조절, 영상(MP4/webm) 저장

모드

  • ⏱ 경기 — 경기 시계 오버레이 (다시 누르면 해제)
  • ⛶ 미팅 — 전체화면 보드 (선수단 미팅용)

2훈련 디자인 — 오늘 세션 만들기

드릴 블록을 쌓아 한 세션을 완성하고, 링크·PDF로 선수단에 전달합니다.

  • ＋ 훈련 디자인하기 — 작전판에 그림을 그리며 새 드릴 작성
  • 📚 라이브러리 — 저장해둔 드릴·기본 템플릿을 "세션에 추가"로 쌓기
  • 각 드릴은 분 × 세트로 시간 설정 (예: 3분 × 3세트 = 9분), 국면·RPE 지정
  • 드릴 카드의 ✎ 편집 — 그림과 텍스트(목적·구성·방법·코칭 포인트) 모두 수정
  • 하단에 총 시간 · 부하 · 국면 분포 바가 자동 집계

완성한 세션은

  • 저장 — 세션 라이브러리에 보관, 불러오기로 재사용
  • 공유(상단) — 선수들에게 링크로 (받는 사람은 읽기 전용으로 봄)
  • PDF로 내보내기 — 인쇄·파일 전달용
  • 주간으로 보내기 — 일정의 원하는 요일에 바로 배치

3라이브러리 — 드릴 은행

  • ＋ 기본 템플릿 14개 — 웜업 4종 + 론도·포지셔닝 게임·게겐프레스·역습 등 실전 드릴
  • 필터: 검색 · 국면 · 내 드릴/기본 · 강도 — 국면을 고르면 어울리는 웜업이 맨 위에 추천됩니다
  • 편집 — 텍스트 수정 + ✏️ 그림 편집으로 작전판 그림까지
  • 세션의 드릴 카드에서 📚 버튼 → 내 드릴로 저장

4일정 — 주간·월간 훈련 계획

주간

  • 경기 있는 날 경기 표시 → 모든 날에 MD(경기까지 며칠)가 자동으로 붙고 권장 강도가 잡힙니다
  • ＋ 훈련 → 위저드: ① 국면·강도 선택 → ② 추천 드릴이 떠서 탭 한 번으로 블록 추가
  • 빈 주에는 ↩ 지난주 그대로 복사 — 복사 후 바꿀 부분만 수정
  • 훈련에 게임모델 원칙을 태그로 연결할 수 있어요

월간 / 그래프

  • 월간: 달력형(1일부터), 좌우 스와이프로 달 이동, 오늘 강조
  • 그래프: 주별 부하 흐름, 지난주 대비 %(급증 시 빨강 경고), 요일별 부하, 국면 배분, 원칙 커버리지
  • 주간·월간·이 날 모두 PDF 내보내기 지원

5게임모델 — 우리 팀의 철학

  • 공격 조직 / 수비 조직 / 공수 전환 4국면 × 세부 국면별로 플레이 원칙을 문장으로 정리
  • 원칙마다 ＋ 작전판 첨부로 그림 연결
  • 여기 적은 원칙이 일정의 훈련 태그와 그래프 커버리지로 이어집니다 — 과정이 쌓여 철학이 되는 구조
  • 완성본은 PDF로 내보내 코칭스태프와 공유

6스카우트 — 선수 평가·보고

  • 속성 탭에서 우리 팀이 쓰는 평가 어휘를 만들고 → 포지션별 목표 레벨(1~5) 설정
  • 선수 등록(우리 선수/스카우트 대상) 후 속성별 현재 레벨 입력
  • 보고서 — 필드에서 포지션 클릭 → 선수 여러 명 선택 → 목표 대비 비교 → 추천 등급과 함께 PDF

7공유 — 링크 하나로 전달

  • 상단 공유: 보드에서 누르면 현재 작전판, 훈련 디자인에서는 오늘 세션, 일정에서는 이번 주 훈련표가 링크로 복사
  • 받은 사람은 앱 설치 없이 읽기 전용으로 봅니다
  • 코치가 받았다면 "내 작전판으로 불러오기"로 가져갈 수 있어요
서버에 저장되지 않습니다 — 데이터가 링크 자체에 압축되어 담겨요. 링크를 아는 사람만 볼 수 있습니다.

8백업 — 데이터 지키기

  • ⚙ → ⤓ 모든 데이터를 JSON 한 파일로 내려받기
  • ⚙ → ⤒ 백업 파일 선택 → 복원 (현재 데이터를 덮어씁니다)
  • 다른 기기로 옮길 때도 이 방법을 쓰면 됩니다

使い方ガイド

戦術ボード · トレーニングデザイン · スケジュール · ゲームモデル · スカウト — 5つのツールをひとつに。インストール不要、スマホ・タブレット・PCのブラウザですぐ使えます。
はじめにボードトレーニングデザインライブラリスケジュールゲームモデルスカウト共有バックアップ

0はじめに

上部にあるのはタブ5つとボタン2つだけです。

  • ボード · トレーニングデザイン · スケジュール · ゲームモデル · スカウト — ツール切り替えタブ
  • 共有 — 今見ているボード・セッション・週間日程をリンクとしてコピー
  • ⚙ 設定 — 言語（한·日·EN）、バックアップのダウンロード/復元、画面プレビュー
📱 スマホでよく使うなら、ブラウザメニューの「ホーム画面に追加」を。アプリのように開けます。
データはこの端末のブラウザに保存されます。端末を替えたりブラウザデータを消すと失われるため、⚙ → バックアップのダウンロードを習慣にしてください。

1ボード — 戦術ボード

戦術を描き、アニメーションにして、画像・動画で書き出します。

選手の配置

  • 上部ベンチの番号トークンをドラッグするか、空のフィールドでフォーメーション（4-4-2など）から11人を自動配置
  • トークンをダブルタップ → 選択：サイズ −/＋、複製、左右/上下反転、削除
  • ボールもダブルタップでサイズ調整できます

描く

  • ツールバー：移動 / ラン（点線） / パス（直線） / ドリブル（波線） / 直線 / 点線 / ペン / ゾーン / 四角形 / テキスト / 消しゴム
  • 表示 ▾にグリッド（5レーン・20ゾーン・3分割）・名簿、もっと見る ▾に保存・書き出し

アニメーション

  • ▶ アニメーション → ＋ 場面で場面を追加しながらトークンを動かすと自動補間
  • 👻 オニオンスキン：前の場面の位置が半透明で重なり、次の場面が作りやすい
  • 完成したら再生・リピート・速度調整、動画（MP4/webm）保存

モード

  • ⏱ 試合 — 試合タイマーのオーバーレイ（もう一度押すと解除）
  • ⛶ ミーティング — フルスクリーンボード（チームミーティング用）

2トレーニングデザイン — 今日のセッション作り

ドリルブロックを積んでセッションを完成させ、リンク・PDFでチームに届けます。

  • ＋ トレーニングをデザイン — ボードに図を描きながら新しいドリルを作成
  • 📚 ライブラリ — 保存済みドリル・基本テンプレートを「セッションに追加」で積む
  • 各ドリルは分 × セットで時間設定（例：3分 × 3セット = 9分）、局面・RPE指定
  • ドリルカードの✎ 編集 — 図とテキスト（目的・構成・方法・コーチングポイント）を両方修正
  • 下部に合計時間 · 負荷 · 局面分布バーが自動集計

完成したセッションは

  • 保存 — セッションライブラリに保管、読み込むで再利用
  • 共有（上部） — 選手にリンクで（受け取った人は読み取り専用で閲覧）
  • PDFに書き出し — 印刷・ファイル送付用
  • 週間に送る — スケジュールの好きな曜日に配置

3ライブラリ — ドリルバンク

  • ＋ 基本テンプレート14件 — ウォームアップ4種 + ロンド・ポジショニングゲーム・ゲーゲンプレス・カウンターなど実戦ドリル
  • フィルター：検索 · 局面 · マイドリル/基本 · 強度 — 局面を選ぶと合うウォームアップが最上部に提案されます
  • 編集 — テキスト修正 + ✏️ 図を編集でボードの図まで
  • セッションのドリルカードの📚ボタン → マイドリルとして保存

4スケジュール — 週間・月間計画

週間

  • 試合のある日に試合を表示 → 全日にMD（試合まで何日）が自動で付き、推奨強度が決まります
  • ＋ トレーニング → ウィザード：① 局面・強度を選択 → ② おすすめドリルが表示され、タップ一回でブロック追加
  • 空の週は↩ 先週をそのままコピー — コピーして変える部分だけ修正
  • トレーニングにゲームモデルの原則をタグとして連携できます

月間 / グラフ

  • 月間：カレンダー形式（1日から）、左右スワイプで月移動、今日を強調
  • グラフ：週ごとの負荷推移、先週比 %（急増は赤の警告）、曜日別負荷、局面配分、原則カバレッジ
  • 週間・月間・この日、すべてPDF書き出し対応

5ゲームモデル — チームの哲学

  • 攻撃の組織 / 守備の組織 / 攻守の切替の4局面 × 細部局面ごとにプレー原則を文章で整理
  • 原則ごとに＋ ボードを添付で図を連携
  • ここに書いた原則がスケジュールのトレーニングタグとグラフのカバレッジにつながります — 過程が積み重なって哲学になる構造
  • 完成版はPDFで書き出してコーチングスタッフと共有

6スカウト — 選手評価・レポート

  • 属性タブでチームの評価語彙を作り → ポジション別に目標レベル（1〜5）を設定
  • 選手を登録（自チーム/スカウト対象）し、属性ごとに現在レベルを入力
  • レポート — フィールドでポジションをクリック → 選手を複数選択 → 目標との比較 → 推薦グレード付きPDF

7共有 — リンクひとつで届ける

  • 上部の共有：ボードで押すと現在の戦術ボード、トレーニングデザインでは今日のセッション、スケジュールでは今週の訓練表がリンクとしてコピーされます
  • 受け取った人はアプリのインストールなしで読み取り専用で閲覧
  • コーチが受け取った場合は「自分のボードに読み込む」で取り込めます
サーバーには保存されません — データはリンク自体に圧縮されて入っています。リンクを知っている人だけが見られます。

8バックアップ — データを守る

  • ⚙ → ⤓ 全データをJSONファイルひとつでダウンロード
  • ⚙ → ⤒ バックアップファイルを選択 → 復元（現在のデータを上書きします）
  • 別の端末へ移すときもこの方法でOK

How to use

Board · Session design · Schedule · Game model · Scout — five tools in one. No install needed; runs in the browser on phone, tablet and PC.
Getting startedBoardSession designLibraryScheduleGame modelScoutSharingBackup

0Getting started

The header is just five tabs and two buttons.

  • Board · Session design · Schedule · Game Model · Scout — tool tabs
  • Share — copies what you're looking at (board, session or weekly plan) as a link
  • ⚙ Settings — language (한·日·EN), backup download/restore, screen preview
📱 If you use it on your phone, tap "Add to Home Screen" in the browser menu — it opens like an app.
Data is stored in this device's browser. It's lost if you switch devices or clear browser data — make ⚙ → backup download a habit.

1Board — tactics board

Draw tactics, animate them, export as image or video.

Placing players

  • Drag numbered tokens from the bench, or auto-place 11 players from a formation (4-4-2 etc.) on an empty field
  • Double-tap a token → select: size −/＋, duplicate, mirror, delete
  • Double-tap the ball to resize it too

Drawing

  • Toolbar: move / run (dashed) / pass (straight) / dribble (wavy) / line / dashed line / pen / zone / rectangle / text / eraser
  • View ▾ holds grids (5 lanes · 20 zones · thirds) and roster; More ▾ holds save & export

Animation

  • ▶ Animation → add scenes with ＋ Scene, move tokens, and it interpolates automatically
  • 👻 Onion skin: the previous scene shows as a translucent ghost, making the next scene easy to build
  • Play, loop, adjust speed, and save as video (MP4/webm)

Modes

  • ⏱ Match — match clock overlay (tap again to exit)
  • ⛶ Meeting — fullscreen board for team meetings

2Session design — build today's session

Stack drill blocks into a session, then send it as a link or PDF.

  • ＋ Design a session — create a new drill while drawing on the board
  • 📚 Library — stack saved drills and starter templates with "Add to session"
  • Each drill uses minutes × sets (e.g., 3 min × 3 sets = 9 min), with phase and RPE
  • ✎ Edit on a drill card — edit both the diagram and the text (objective, setup, method, coaching points)
  • The footer auto-totals time · load · phase distribution

When the session is done

  • Save — stored in the session library, reuse with Load
  • Share (header) — send to players as a link (they see a read-only view)
  • Export to PDF — for print or file handoff
  • Send to week — drop it onto any day of the schedule

3Library — your drill bank

  • ＋ 14 starter templates — 4 warm-ups plus rondos, positioning games, counter-press, counters and more
  • Filters: search · phase · my drills/built-in · intensity — pick a phase and matching warm-ups float to the top
  • Edit — text editing plus ✏️ Edit diagram for the board drawing
  • The 📚 button on a session drill card saves it as your own drill

4Schedule — weekly & monthly planning

Weekly

  • Mark Match on matchdays → every day gets an MD (days to match) tag with recommended intensity
  • ＋ Training → wizard: ① pick phase & intensity → ② suggested drills appear; one tap adds a block
  • On an empty week, ↩ Copy last week — then change only what differs
  • Tag trainings with your game model principles

Monthly / Graph

  • Monthly: true calendar (from the 1st), swipe to change months, today highlighted
  • Graph: weekly load trend, % vs last week (red warning on spikes), load by day, phase mix, principle coverage
  • Weekly, monthly and daily views all export to PDF

5Game model — your team's philosophy

  • Write play principles across the four phases (attacking, defending, both transitions) and their sub-phases
  • Attach a board diagram to any principle with ＋ Attach board
  • Principles flow into schedule tags and the graph's coverage — the process accumulates into philosophy
  • Export the finished model as a PDF for your staff

6Scout — player evaluation & reports

  • Build your team's evaluation vocabulary in Attributes → set target levels (1–5) per Position
  • Register Players (own squad / targets) and enter current levels per attribute
  • Report — click a position on the field → select players → compare against targets → PDF with a recommendation grade

7Sharing — one link delivers it

  • The header Share button copies the current board, today's session, or this week's schedule — depending on the tab you're on
  • Recipients view it read-only, no install needed
  • A coach can pull a shared board into their own with "Load into my board"
Nothing is stored on a server — the data is compressed into the link itself. Only people with the link can see it.

8Backup — protect your data

  • ⚙ → ⤓ downloads all data as a single JSON file
  • ⚙ → ⤒ pick a backup file → restore (overwrites current data)
  • Use the same method to move to another device
