# PROCESS · 과정에 몰입하라

코치를 위한 한국형 코칭 학습 플랫폼 PROCESS의 홈페이지입니다.
마스터클래스 · 현장 인터뷰 · 훈련 프로그램 · 앱(PWA)을 소개합니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메인 홈페이지 |
| `course.html` | 전력분석 강의 (입문·심화 8강) |
| `manifest.json` | PWA 설정 (앱 설치용) |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `instructor.jpg` | 강사 이미지 |

## 로컬에서 보기

별도 빌드가 필요 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 협업 규칙

- 작업은 각자 브랜치를 만들어 진행하고, `main`에는 Pull Request로 합칩니다.
- 커밋 메시지는 무엇을 바꿨는지 한 줄로 적어주세요.

### 2026-06-12 — PROCESS STUDIO 앱 대규모 업데이트 (`process-studio.html` 저장소 편입)
스튜디오 단일 파일 앱을 저장소에 편입. 기존 사용자 데이터(localStorage)와 완전 호환.

**보드**
- 선수 토큰을 유니폼(셔츠) 모양으로 — 보기 메뉴에서 원형/유니폼 선택, 기본 라벨은 포지션
- GK 기본색 분리(네이비팀=하늘, 레드팀=노랑), 토큰 더블클릭 = 자유 색상 변경(팀 전체 적용)
- 그리기 도구·선수 팔레트 기본 접힘 → 버튼으로 운동장 위에 떠오름(운동장 크기 불변), 운동장이 화면의 82~95%
- 경기·미팅을 툴바 우측(보여주기 묶음)으로 이동, 워크플로우 순서 정렬, 폰 툴바 여백·잘림 정리
- 미팅 모드 프레젠테이션: ←→ 장면 슬라이드(리모컨 호환), S 스포트라이트, B 블랙아웃
- 텍스트: 탭한 자리에서 바로 입력·수정, ± 크기 조절 / 드래그 렉 수정(가이드 레이어 재부착 제거, 드래그 중 그림자 차단)
- 애니메이션 영상 저장: vp9-mp4 함정 제거(QuickTime 호환), webm 시 안내

**훈련 디자인**
- ⚡ 빠른 추가(이름+Enter), ⠿ 드래그로 블록 순서 이동, 카드 컨트롤 전부 인라인 노출
- 자동 기록: 제목/날짜 입력 시 기록부에 자동 저장(수동 저장 버튼 제거, linkId로 중복 방지)
- 날짜 입력 → 일정 앱 해당 날짜에 자동 등록(날짜 변경 시 이동, 중복 없음)
- 헤더 정리(저장·불러오기·PDF 등 → ⋯ 세션 메뉴), 현장 시트(A4 런시트 인쇄) 주 버튼화, 현장 모드는 아이패드 거치용 보조
- 기록부(불러오기): 날짜순 정렬 + 드릴 구성·시간·RPE 표시 / 국면 분류에 웜업 추가
- 에디터: 날짜·시간·인원 맨 위, 폰 텍스트 우선(운동장 토글), 선수 토큰 축소

**팀 (구 스카우트)**
- 탭명 팀으로 변경, 선수 탭 첫 화면(우리 선수단/스카우트 대상 두 열)
- 팀 구성: 포메이션 기반 운동장(커스텀 포메이션 제작 가능), 포지션별 이름 스택(최대 5명, 겹침 방지), 순위 ▲▼(주전 위), 그룹 자유 지정(1군·2군·A팀… 칩 필터), 유니폼·GK 색 선택
- 스카우트: 팀 구성과 동일 구조(운동장+대상 명단), 포지션 클릭 → 우리 선수 vs 대상 자동 비교, 포지션별 "찾는 유형" 메모
- 기준 설정: 포메이션 공유, 속성 카테고리 자유 편집(접이식), 속성 인라인 ✎ 수정
- 포지션 12종(GK CB LCB RCB LB RB DM CM AM CF LW RW) + 표준 등번호 자동, CB 누락 버그 수정
