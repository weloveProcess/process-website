# 홈 첫 화면 — 작전판 중심 구성

processfootball.com 첫 화면을 «작전판으로 훈련을 만들고 전술을 설명한다»는 내용으로 바꾸는 파일 묶음입니다.
2026-11-10 에 라이브 사이트에서 내려받은 `index.html` 을 바탕으로 만들었습니다.

## 파일

| 파일 | 올릴 곳 | 설명 |
| --- | --- | --- |
| `assets/home-board.css` | `/assets/home-board.css` | 새 구역 스타일. 클래스가 모두 `hb-` 로 시작해 기존 스타일과 겹치지 않습니다. |
| `assets/home-board.js` | `/assets/home-board.js` | 첫 화면 작전판 예시(전술 설명 · 훈련 만들기) 재생. |
| `main-top.html` | — | 레터 구역 **앞**에 들어가는 내용(첫 화면, 두 갈래, 실제 앱 화면, 팀 운영). |
| `main-bottom.html` | — | 레터 구역 **뒤**에 들어가는 내용(교과서 · 24개 주제 · 허브). |
| `apply.py` | — | 위 조각을 `index.html` 에 끼워 넣는 스크립트. |
| `index.html` | `/index.html` | 2026-11-10 라이브 홈에 적용해 본 결과(미리 보기용). |

## 적용

```bash
python3 apply.py <원본 폴더>/index.html <원본 폴더>/index.html
cp assets/home-board.css assets/home-board.js <원본 폴더>/assets/
```

- «프로세스 레터 · 이번 주의 콘텐츠» 구역(`<div id="letter">`)과 헤더 · 푸터 · 공유 미리보기 구역은 그대로 둡니다.
- 여러 번 돌려도 결과가 같습니다.

## 주의 — 매일 갱신

라이브 사이트는 «매일 갱신» 배포가 `index.html` 을 다시 만듭니다. 그 스크립트가 홈 전체를 새로 쓰면
위 변경이 다음 날 사라집니다. 둘 중 하나로 막습니다.

1. 매일 갱신 스크립트에서 배포 직전에 `apply.py` 를 한 번 돌린다.
2. 스크립트의 홈 원본(템플릿)에 `main-top.html` · `main-bottom.html` 내용을 옮긴다.

## 확인할 것

- 제목과 설명 문구(`apply.py` 의 `TITLE` · `DESC`)를 바꿨습니다. 공유 미리보기(og) 문구와 그림은 그대로입니다.
- 작전판 예시는 설명용으로 새로 그린 것입니다. 선수 표식과 화살표 모양은 앱 작전판과 다릅니다.
- «이미지나 영상으로 내보낼 수 있습니다» 같은 기능 문구가 앱의 실제 범위와 맞는지 확인하세요.
